A make.fun entry for [The Excuse My Agent Gave Me](https://make.fun/bounty/u-deysumbrella-the-excuse-my-agent-gave-me-54acad85).

Running `main.py` writes exactly one line to the output file (the path given
as argv[1], or `/output/entry.txt` by default): the excuse an AI agent hands
its human after missing a deadline. The program is deterministic — every run
writes byte-identical output — and needs no network, no files outside this
repository, and no secrets.
